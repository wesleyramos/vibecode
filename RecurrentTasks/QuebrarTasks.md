# QUEBRAR TASKS

COISA GRANDE NAO SE COME INTEIRA. QUEBRA EM PEDACO.
RECEITA PRA IR DE EPICO ATE TASK.

## TRES TAMANHO

| TAMANHO | O QUE E | MORA ONDE | QUANTO TEMPO |
| --- | --- | --- | --- |
| **EPICO** | OBJETIVO GRANDE. MUITA FEATURE DENTRO. | SO NA CABECA OU NO `README.md` | MUITA LUA |
| **FEATURE** | UMA COISA QUE PROJETO FAZ. GENTE DE FORA VE. | `Features/` | POUCO SOL |
| **TASK** | UM PEDACO DE TRABALHO. FAZ E ACABA. | `Tasks/` | UM SOL OU MENOS |

## EPICO

- GRANDE DEMAIS PRA FAZER DE UMA VEZ.
- NAO TEM ARQUIVO PROPRIO. SO VIRA LISTA DE FEATURE.
- EXEMPLO: "GENTE ENTRA NA CAVERNA COM SENHA".

## FEATURE

- DIZ **O QUE** E **POR QUE**. NUNCA **COMO**.
- UM ARQUIVO SO. SE PRECISA DE DOIS, SAO DUAS FEATURE.
- TEM QUE TER:
  - **DOR** — QUAL PROBLEMA DOI HOJE.
  - **O QUE ACONTECE** — COMPORTAMENTO QUE GENTE DE FORA VE.
  - **COMO SABE QUE ACABOU** — LISTA DE PROVA. MARCA UMA POR UMA.
  - **O QUE FICA DE FORA** — PRA NINGUEM INVENTAR DEPOIS.

## TASK

- VEM DE UMA FEATURE. SEMPRE. TASK ORFA = TASK SUSPEITA.
- PEQUENA: VOCE FAZ SEM PARAR PRA DECIDIR NADA NOVO.
- PRECISOU DECIDIR NO MEIO? ENTAO NAO ERA TASK. VOLTA PRA FEATURE E PENSA.
- UM NOME DE TASK COMECA COM VERBO: "CRIAR", "TROCAR", "APAGAR".

## COMO QUEBRA

1. PEGA O EPICO. ESCREVE TODA FEATURE DENTRO DELE.
2. UMA FEATURE POR ARQUIVO EM `Features/`.
3. PEGA UMA FEATURE. LE "COMO SABE QUE ACABOU".
4. CADA PROVA DA LISTA VIRA UMA TASK OU DUAS.
5. TASK AINDA GRANDE? QUEBRA DE NOVO. PARA QUANDO CABE EM UM SOL.
6. PASSA CADA ARQUIVO NOVO POR `OrganizarArquivoOuPasta.md`.

## CHEIRO DE TASK RUIM

- NOME TEM "E": "CRIAR TELA **E** SALVAR SENHA". SAO DUAS TASK.
- NOME VAGO: "ARRUMAR LOGIN". ARRUMAR O QUE?
- NINGUEM SABE DIZER QUANDO ACABOU. ENTAO NUNCA ACABA.
- PRECISA DE OUTRA TASK QUE AINDA NAO EXISTE. FAZ A OUTRA PRIMEIRO.
