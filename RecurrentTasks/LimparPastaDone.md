# LIMPAR PASTA DONE

RECEITA. SEGUE PASSO. NAO PULA.
USA QUANDO: `Tasks/Done/` TA CHEIA. OU TODA LUA. O QUE VIER PRIMEIRO.

## POR QUE

**TASK E O CAMINHO, NAO O FIM.**
TASK FECHADA E OSSO ROIDO. VOCE JA COMEU A CARNE.

**TASK NUNCA E FONTE DE VERDADE.** ARQUIVO VIVO DO PROJETO E.
VERDADE ESCONDIDA NUMA TASK MORTA NINGUEM ACHA. NINGUEM LE PASTA `Done/`.
ENTAO: TIRA A VERDADE DE DENTRO, POE NO ARQUIVO VIVO, DEPOIS MATA A TASK.

## PASSO

### 1. LE A TASK FECHADA ATE O FIM

PROCURA COISA QUE AINDA VALE AMANHA:

- DECISAO QUE ALGUEM TOMOU, E O MOTIVO DELA.
- PALAVRA NOVA QUE A TRIBO COMECOU A USAR.
- COMPORTAMENTO QUE O PROJETO AGORA TEM.
- PEGADINHA, ARMADILHA, "NAO FACA ISSO AQUI".
- PASSO QUE VOCE REPETIU E VAI REPETIR DE NOVO.

### 2. MANDA CADA COISA PRA CAVERNA CERTA

| ACHOU ISSO | VAI PRA |
| --- | --- |
| DECISAO DE COMO CODIGO E ARRUMADO | `Code/ARCHITECTURE.md` |
| PALAVRA NOVA DO PROJETO | `GLOSSARY.md` |
| MUDANCA QUE GENTE DE FORA VE | `CHANGELOG.md` |
| COMPORTAMENTO QUE O PROJETO FAZ | `Features/` |
| PASSO QUE REPETE SEMPRE | `RecurrentTasks/` (RECEITA NOVA) |
| ESCOLHA DE COMO CONTA VERSAO | `VERSIONING.md` |
| COR, LETRA, TELA | `Design/` |
| NADA DISSO. SO CONVERSA DO DIA. | LUGAR NENHUM. DEIXA MORRER. |

ESCREVE NA VOZ DO ARQUIVO QUE RECEBE. NAO COLA TEXTO DE TASK NO MEIO DE PAPEL VIVO.

### 3. CONFERE ANTES DE MATAR

- TODA COISA DO PASSO 1 TA EM ALGUM ARQUIVO VIVO AGORA? LE E CONFIRMA.
- ARQUIVO QUE RECEBEU CONTINUA CONSISTENTE? NAO FICOU DOIS PEDACO SE BRIGANDO?
- FICOU NA DUVIDA SE IMPORTA? **PERGUNTA PRA TRIBO. NAO ADIVINHA.**

### 4. MATA A TASK

```sh
git rm Tasks/Done/<task>.md
```

**GIT GUARDA O OSSO.** TEXTO NAO SOME DO MUNDO, SO SAI DA FRENTE.
MEDO DE APAGAR E MEDO DE PERDER. GIT NAO PERDE.

### 5. FECHA O OSSO

COMMIT COM MARCA `LIMPOU`. LE `COMMIT.md`.
MUDOU ARQUIVO VIVO E MATOU TASK NO MESMO SOL? PODE IR NO MESMO OSSO,
SE FOR A MESMA VERDADE ANDANDO DE UM LUGAR PRO OUTRO.

## LEI

- PASTA `Done/` NAO E MUSEU. NAO GUARDA TASK PRA LEMBRAR.
  QUER LEMBRAR? ENTAO A COISA E VERDADE. VERDADE VAI PRO ARQUIVO VIVO.
- NUNCA MATA TASK SEM FAZER O PASSO 1. PRESSA AQUI CUSTA LUA DEPOIS.
- MESMA VERDADE EM DOIS ARQUIVO VIVO = BRIGA FUTURA. ESCOLHE UM DONO.
- TASK AINDA ABERTA NAO ENTRA NESSA RECEITA. SO TASK FECHADA.

## CHEIRO DE PASTA DONE RUIM

- TASK DE TRES LUA ATRAS AINDA LA. NINGUEM OLHA. SO OCUPA LUGAR.
- TRIBO ABRINDO TASK VELHA PRA SABER COMO O PROJETO FUNCIONA.
  ISSO E GRITO: A VERDADE TA NO LUGAR ERRADO.
- TASK FECHADA COM COISA ESCRITA QUE NAO EXISTE EM NENHUM ARQUIVO VIVO.
- PASTA `Done/` MAIOR QUE A PASTA `Tasks/`. MORTO MANDANDO NO VIVO.
