## CAVERNA POR CAVERNA

- **`Code/`** — CODIGO QUE RODA. `Code/ARCHITECTURE.md` EXPLICA ARRUMACAO.
  MUDA ARRUMACAO? MUDA PAPEL TAMBEM.

- **`Design/`** — COR, LETRA, TELA, DESENHO. `Design/Assets/` GUARDA FIGURA PESADA.

- **`Features/`** — UM ARQUIVO, UMA COISA QUE PROJETO FAZ.
  DIZ **O QUE** E **POR QUE**. NAO DIZ COMO. COMO E DEPOIS.

- **`Tasks/`** — PEDACO DE TRABALHO. PEQUENO. VOCE FAZ SEM PENSAR MUITO.
  PENSAR MUITO = AINDA NAO E TASK.
  `Tasks/Done/` GUARDA TASK FECHADA ATE A LIMPEZA. NAO E MUSEU.

- **`RecurrentTasks/`** — RECEITA, NAO HISTORIA. VOCE SEGUE PASSO.
  - `ChecarSeguranca.md` — SEGREDO SOLTO? LIB COM FURO? CLASSIFICA A DOR.
  - `LimparPastaDone.md` — TASK FECHADA MORRE. VERDADE DELA FICA VIVA.
  - `OrganizarArquivoOuPasta.md` — ARQUIVO NO LUGAR? ARQUIVO PRECISA EXISTIR?
  - `QuebrarTasks.md` — COISA GRANDE VIRA COISA PEQUENA.

## COMO USA EM PROJETO NOVO

1. PEGA A CASCA. JOGA MEMORIA VELHA FORA:
   ```sh
   git clone --depth 1 <url-deste-repo> MeuProjeto
   cd MeuProjeto
   rm -rf .git && git init
   ```
2. ESCREVE `README.md` DE NOVO. FALA DO **SEU** PROJETO. NAO DA CASCA.
3. POE PRIMEIRA PALAVRA NO `GLOSSARY.md`.
4. ESCREVE PRIMEIRA FEATURE. QUEBRA EM TASK.
5. ARRUMA `.gitignore` PRA SUA FERRAMENTA.
6. RODA `RecurrentTasks/ChecarSeguranca.md` ANTES DE ABRIR O REPO PRO MUNDO.
